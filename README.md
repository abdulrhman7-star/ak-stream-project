# أكوام برو — Flask

مشروع Flask مبني على المواصفات والكود الواردين في الملف المرفق.

## التشغيل

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

ثم افتح:
http://127.0.0.1:5001

> استخدم المحتوى والروابط فقط عندما تملك الحق القانوني في الوصول إليها وعرضها.
